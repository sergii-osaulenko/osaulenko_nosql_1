# Аналітична платформа для музичного стрімінгового сервісу (MongoDB NoSQL)

Цей проєкт є практичною реалізацією документоорієнтованої бази даних на платформі **MongoDB Atlas** для музичного стрімінгового сервісу — конкурента Spotify. У рамках проєкту проведено завантаження сирого датасету (~114 000 треків), трансформацію плоскої структури CSV у документоорієнтовану схему через Aggregation Pipeline, побудову складних аналітичних звітів та профілювання запитів за допомогою індексів з доведенням їх ефективності через `explain("executionStats")`.

---

## 1. Налаштування оточення та покроковий запуск проєкту

### 1.1. Передумови та системні вимоги
Для запуску проєкту на вашому комп'ютері повинні бути встановлені:
- **Python 3.10+**
- **MongoDB Shell (`mongosh`)** (для виконання MQL-скриптів та перевірки планів виконання)
- Окремий або безкоштовний Shared-кластер **MongoDB Atlas (M0)**

### 1.2. Підготовка віртуального середовища та встановлення залежностей
